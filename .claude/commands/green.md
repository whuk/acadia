Make the failing test pass (Green phase of TDD).

1. Identify the currently failing test
2. Implement the MINIMUM code needed to make it pass:
   - Use the simplest solution that could possibly work
   - No extra features or edge cases
   - No premature optimization
   - No refactoring yet
3. Run all tests to confirm they ALL pass
4. Report what was implemented and test results

Rules:
- Write just enough code to pass the test - no more
- If multiple tests are failing, focus on ONE at a time
- Do NOT refactor in this phase
- Keep implementation simple and direct
