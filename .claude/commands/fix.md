Fix a defect following TDD methodology.

1. First, write an API-level failing test that exposes the bug
2. Then, write the smallest possible test that replicates the specific problem
3. Run tests to confirm both new tests fail
4. Implement the fix with minimum code changes
5. Run all tests to confirm they ALL pass
6. Report the bug, tests written, and the fix applied

$ARGUMENTS - Description of the defect to fix
