plan.md를 읽고 다음 미완료 테스트(체크 표시가 없는 테스트)를 찾으세요.

1. 해당 테스트 하나만 구현하세요
2. 테스트를 실행하여 실패를 확인하세요 (Red 단계)
3. 테스트를 통과시키기 위한 최소한의 코드를 구현하세요
4. 모든 테스트를 실행하여 통과를 확인하세요 (Green 단계)
5. plan.md에서 해당 테스트에 체크 표시를 하세요

하지 말아야 할 것:
- 여러 테스트를 한꺼번에 구현하기
- 테스트 통과에 필요한 것 이상의 코드를 추가하기
- 이 단계에서 리팩터링하기
- 실패 테스트 검증을 건너뛰기

어떤 테스트를 구현했는지와 테스트 결과를 보고하세요.
