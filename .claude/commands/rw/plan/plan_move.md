프로젝트 루트의 plan.md 파일을 읽고 내용을 요약한 뒤, 요약 키워드가 포함된 파일명으로 변경하여 plans 디렉토리로 아카이빙한다.

1. 프로젝트 루트의 `plan.md`를 Read 도구로 읽는다. 파일이 존재하지 않으면 사용자에게 알리고 중단한다.
2. 파일 내용을 분석하여 핵심 주제를 나타내는 3~5단어의 한글 요약 키워드를 생성한다.
   - 요약 키워드는 밑줄(`_`)로 연결한다 (예: `사용자_인증_기능_구현`)
   - 공백, 특수문자, 영문 대문자를 키워드에 포함하지 않는다
3. 오늘 날짜를 `yyyyMMdd` 형식으로 구하고, 새 파일명을 결정한다: `plan_yyyyMMdd_요약키워드.md`
4. 프로젝트 루트에 `plans/` 디렉토리가 존재하는지 확인한다. 없으면 `mkdir -p plans`로 생성한다.
5. `mv plan.md plans/새파일명.md` 명령으로 파일을 이동한다.
6. 결과를 보고한다:
   - 원본 파일: `plan.md`
   - 새 파일명: `plan_yyyyMMdd_요약키워드.md`
   - 이동 경로: `plans/plan_yyyyMMdd_요약키워드.md`
   - plan.md 내용 요약 (2~3문장)

하지 말아야 할 것:
- plan.md가 없는데 빈 파일을 생성하기
- 요약 키워드에 공백이나 특수문자 포함하기
- 기존 plans 디렉토리 내 동일 파일명이 있을 때 덮어쓰기 (충돌 시 사용자에게 확인 요청)
- plan.md 원본 내용을 수정하기
